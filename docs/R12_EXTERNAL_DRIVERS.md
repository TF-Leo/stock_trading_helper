## 1. 三个命题与预注册判据（原文照录，未改动阈值）

**H1 建模层**：仅用「外币、外股、外汇、外债」四类外部变量，能否得到对 A 股指数走势「极其贴合」的拟合。

- 因变量：沪深300（周频与月频各一套），使用**收益率**而非指数水平值。
- 基准 A（天真）：随机游走 / AR(1)；
- 基准 B（国内）：M2 同比、DR007/SHIBOR、两融余额增速、北向净流入（若可得）；
- 模型 C（外部四因子）：USDCNY 变动、S&P500 与恒生收益、美债 10Y 变动、（可选）中美利差。
- **成立**：样本外 R²(C) ≥ 0.20 **且** 比 max(基准A, 基准B) 高 ≥ 0.10；方向命中率 > 55%。
- **推翻**：样本外 R²(C) ≤ 0.05，或不如基准 B。

**H2 结构层**：全 A 个股滚动 2 年日频市场模型。

- **成立**：市场模型 R² 中位数 ≥ 0.50，且个股 alpha 的 |t|>2 比例 ≤ 10%；
- 同时给出美国样本的同方法对照，说明「Beta 主导」是否 A 股特有。

**H3 博弈层**：合谋资金 → 高管参与 → 质押加杠杆 → 批量收割。

- **不可因果检验**。只做一致性检验（质押比例变化 vs 后续回撤、两融增速 vs 后续波动），
  结论必须写明「相关不等于因果，不能证实该链条」。

方法纪律：只用收益率/差分；做单位根与自相关检验；样本外必须真正扩展窗口；
报告**所有尝试过的模型**（含失败的）；数据来源与获取时间入报告；结论分级（支持/不支持/无法判定）。

### 1.1 本次修订对判据的处理

- H1：预注册的 0.20/0.10/55% 三条**原样保留**。修订只是把「同一期间」拆成两档，
  并把**信息可得**档作为「可交易/可预测」口径。原实现的 0.391 保留为对照，
  不再作为 headline。
- H2：R² 中位 ≥0.50 原样保留。alpha 判据的**原阈值 ≤10%** 保留在结果表里，
  但同时证明它在零假设下**没有判别力**；因此不再用它给「Alpha 很弱」定级，
  改用有零分布的 λ/τ + 组合 alpha，并用安慰剂/功效测试验证（见 §3.2、§4.2.4）。
- H3：不变。

## 3. 方法

### 3.1 H1（周频 / 月频各一套）

- 频率：周频 = 每周最后一个交易日；月频 = 每月最后一个交易日。
- 因变量：`log(close_t) − log(close_{t−1})`。
- **对齐（本次修订的核心）**：
  - `period`（PR 原实现）：各市场按自己的 `W-FRI`/`M` 取期间最后一根，再按 Period 对齐。
    第 t 周的 S&P500 收益包含**周五美股夜盘（周六 04:00 CST 才收盘）**，恒生包含**周五 15:00–16:00**
    （A 股 15:00 已收盘）；月频同理。这是「同一期间 + 收盘后重叠」口径。
  - `samegrid`：各外盘先按自己的 Period 取最后一根，对齐到 A 股 Period 网格后再取差分。
    与 `period` 的差别只在 A 股节假日截断周（原实现先差分后对齐）；两者都属于「同一期间」。
  - **`avail`（信息可得，主口径）**：对每个 A 股期间末交易日 D，取该外盘 **`date < D` 的最后一根**。
    A 股 15:00 收盘时，恒生当日 16:00 收盘、美股当日 21:30–次日 04:00 的夜盘、FRED `DGS10` 的美东收盘
    都尚未发生，因此只能用前一个外盘收盘。窗口右端与左端同时前移，**窗口长度不变**。
  - 两融、北向为收盘后披露 → `shift(1)`；M2 按「次月可得」→ `shift(1)` 后前向填充；
    SHIBOR 日内可得 → 同期。
  - 严格可交易版：全部外部因子再滞后一整期（`_lag`）。这是**保守下界**：它把恒生同一时段的
    重叠也全部丢掉，因此会低估可得信息（见 §4.1.3、§6.1）。
- 基准：
  - A1 随机游走（预测 0）、A2 扩展窗口 AR(1)；
  - B 国内因子 OLS；
  - C 外部四因子 OLS。
- 样本外：**扩展窗口**，首次训练截至 2018-12-31，2019-01 起逐期预测；每期重新估计。
- 指标：
  - OOS R² = 1 − SSE(model)/SSE(扩展窗口历史均值)，标准 Campbell–Thompson 口径；另报相对 0 的口径；
  - 方向命中率 = sign(预测) 与 sign(实际) 一致的比例（剔除 0）；
  - Diebold–Mariano（平方损失，Newey–West）；
  - in-sample R²（截至 2018-12-31）与全样本系数 t 值。
- 单位根/自相关：自实现 ADF（含常数，BIC 选 0–4 阶）与 ACF(1)。
- **因子分解**：对四因子、仅恒生、仅 S&P500、仅 USDCNY（在岸/离岸）、仅美债 10Y 分别在同一期间
  与信息可得两档下重跑同一套扩展窗口，给出逐因子 OOS R² 与命中率。
- **日频 lead-lag 佐证**：A 股对数收益与同日/前一日/后一日外盘收益的相关；前一日用外盘自己的
  上一交易日（A 股开盘前已知）。样本自 2017-03 起，与周频主设定一致。

### 3.2 H2

- 市场模型：`r_i,t = α + β·r_m,t + ε`，日频简单收益。
- 窗口：2 年（约 500 交易日），终点取 2021–2026 每年年末，窗口互相重叠。
- 有效样本：窗口内 ≥ 400 个交易日；剔除 |日收益| > 50% 的脏数据；只用 `tradestatus == 1`；
  相邻有效交易日间隔 > 10 个自然日的收益置 NaN（长期停牌复牌）。
- 分布：R² 中位数与四分位、R² ≥ 0.50 占比、beta 中位数；分窗报告。
- **可比池（本次修订）**：
  - `全A`：R9 无偏池全部 5471 只（含退市），**补充口径**；
  - `沪深300成分`：2026-11-09 当前名单 ∩ 有 2022–2024 有效窗口的股票；
  - `成交额top300` / `成交额top50`：按 2022-12-31→2024-12-31 中位日成交额固定排名；
  - `成交额top300(逐窗)` / `top50(逐窗)`：每个窗口内按该窗平均成交额重新排名（稳健性，无未来流动性）；
  - `美股50`：道指/大市值公开名单 vs S&P 500，同方法、同窗口、同门槛。
- **alpha 判据（修订）**：
  - 旧判据：个股 alpha 的 |t|>2 比例 ≤10%。保留为对照，但证明其零假设期望约 5%，
    且打乱市场的安慰剂只有约 0.8%，**没有判别力**。
  - 新统计量：
    * `λ = SD(α̂_i) / sqrt(mean(SE_i²))`：横截面 alpha 离散 / 估计噪声。λ<1 表示估计量分不清
      alpha 与噪声（检验没功效）；λ>1 表示存在超出抽样噪声的横截面离散。
    * `τ = sqrt(max(Var(α̂_i) − mean(SE_i²), 0))`：随机效应方差分解，扣掉估计噪声后的真实
      alpha 离散（年化）。τ=0 表示数据与「所有个股 alpha 相同（通常 0）」相容。
    * **组合层 alpha**：池内个股等权日度再平衡成组合，对市场做 Newey–West(5) 回归；
      这是对**共同 alpha** 的检验。另对**等权全 A 市场**回归，用于判断组合 alpha 是否只是
      等权/规模效应。
  - 零分布：残差块 bootstrap（块长 20 个交易日 ≈ 一个月），保留每只股票残差的厚尾/波动聚集；
    每窗口 B=100 次。`p_lambda = P(λ* ≥ λ_obs)`，`p_port = P(|t*| ≥ |t_obs|)`。
  - 功效：在同一 bootstrap 中注入**共同 alpha** 与**横截面 alpha 离散**（年化 5%/10%/20%），
    报告检出率（新统计量超过零分布 95 分位）。
  - **判据**：只有「λ 显著（p<0.05）或组合 alpha 显著（p<0.05）」才拒绝「alpha≈0」；
    若两者都不显著且 5%/年信号的功效 <80%，则「Alpha 很弱」只能判**无法判定**（功效不足），
    不能判「支持」。若组合 alpha 显著但相对等权全 A 市场不显著，则归因为**基准/等权/规模效应**，
    不作为「个股 alpha」的证据。
- 美国对照：50 只大市值美股 vs S&P 500，同方法、同窗口、同门槛。
  **这是「同方法对照」，不是全美股样本**；大市值样本会**高估**美股 R²，因此对照结论偏保守。

### 3.3 H3

- 质押：月末中位质押比例、质押比例 ≥30% 的股票占比；一阶差分。
- 后续风险：从快照后第一个交易日起，未来 20/60 个交易日的最大回撤（相对当前收盘）。
- 两融：周/月对数增速 vs 未来 20 日实现波动；另跑与未来 20 日回撤。
- 统计：Spearman ρ + 20,000 次置换检验 p 值（不依赖 scipy）。
- **只报相关，不做因果识别**。

#### 4.2.1 可比池结果（主结论）

**全 A 为什么低：构成，不是「A 股不 Beta」。**

- 全 A 的 2 年窗口平均日成交额中位仅 **1.26 亿元**；沪深300 成分 **7.11 亿元**；top50 **23.1 亿元**。
  全 A 池包含大量小盘/低流动性/新上市与退市股票，日收益被特质噪声主导。
- 按窗口平均成交额分十档（2024 窗口），R² 中位从最低档 **0.165** 单调升到最高档 **0.217**；
  流动性越高的股票，市场因子解释力越强。全 A 的 0.124 是小盘/低流动性档占比过高的**加权结果**，
  不能直接与美股 50 只大市值比较。
- **更正原 §4.2「若用同等大市值口径，A 股的解释力只会更低」**：实测方向相反——
  全 A 0.124 → 沪深300 成分 **0.217**，是**上升**。该句已删除并改为实测值。

**判读**

- **预注册的「R² 中位 ≥0.50」在可比池下仍不满足**：0.200–0.247，远低于 0.50；
  R²≥0.5 占比只有 2.2%–6.8%。**「Beta 主导」不支持。** Beta 中位 0.96–1.30，
  说明**敏感度**正常；问题在**解释力**——市场因子只解释 20%–25% 的个股日收益方差。
- **「A 股个股 R² 低于美股」仍成立，但差距减半**：可比池 0.200–0.247 vs 美股 0.318，
  差距约 **0.07–0.12**；全 A 口径的差距是 0.194。原报告用全 A 与美股 50 比，把差距夸大了约一倍。
- **「Beta 主导是 A 股特有」不支持**：美股 50 只大市值 R² 中位 0.318 高于 A 股可比池。
- 幸存者偏差方向：沪深300 用**当前**成分回溯，会剔除后来调出的差股票，**抬高** R² 与 alpha；
  因此 0.217 仍偏乐观，真实历史成分只会更低。这不改变「<0.50」的结论。

#### 4.2.2 原 alpha 判据为什么失效

旧判据：个股 alpha 的 |t|>2 比例 ≤10%。它在**零假设下的期望约为 5%**，
所以「≤10%」几乎任何池子都会通过；它不能区分「alpha 弱」与「检验没功效」。

- **纯高斯噪声**过同一套 OLS 管道（n=500，20,000 次）：|t|>2 = **4.6%**
  （复核报告用同一管道的 4.0% 在模拟误差内；见 `h2_results.json` 的 `gaussian_calibration`）。
- **打乱市场安慰剂**（同一管道，把市场收益随机打乱，破坏全部真实关系）：
  全 A 池 |t|>2 = **0.8%**。这不是「alpha 更弱」，而是打乱市场后 beta 关系被破坏、
  残差方差被股票自身的市场成分撑大，t 被压小——**安慰剂本身不是 alpha 的零分布**。
- 全 A 的 1.7% 低于名义 5%，原因不是 alpha 更弱，而是**估计噪声大于横截面离散**：
  SD(α̂)=25.9%/年，RMS(SE)=32.5%/年，λ=**0.796**<1。也就是说，全 A 的 alpha 估计
  分不清 alpha 与噪声；1.7% 是**检验没功效**的表现，不是「alpha 很弱」的证据。
- 可比池的 5.1%/5.5%/9.6% 才接近或高于名义 5%，说明这些池子里**可能有**超出噪声的 alpha；
  但这仍不是「alpha 很弱」。

#### 4.2.3 新 alpha 判据的结果

> 判据定义、零分布与功效测试见 §3.2。λ/τ 衡量**横截面 alpha 离散**；组合 alpha 衡量**共同 alpha**。

- **全 A**：λ=0.796、τ=0（横截面离散低于估计噪声）；平均 α=11.9%/年，但这是等权平均，
  被小盘/低流动性股票的估计噪声主导，不能当作可交易 alpha。
- **沪深300 成分**：λ=1.060、τ=9.1%/年；**top300** λ=1.064、τ=11.1%；
  **top50** λ=1.116、τ=14.8%。相对全 A，可比池确实有更多「超出噪声」的横截面离散，
  但幅度不大，且逐窗 bootstrap 的 p 值并不稳定（见下表）。
- **组合层 alpha**：池内等权组合相对沪深300 的年化 alpha，沪深300 成分为 **8.6%–34.9%**、
  top300 为 **3.9%–28.4%**、top50 为 **14.7%–34.9%**；HAC(5) t 值在沪深300 成分 **6/6** 窗口
  |t|>2（bootstrap p<0.05 为 5/6）、top50 **5/6**、top300 **4/6**。看起来「有 alpha」。
- **但相对等权全 A 市场，组合 alpha 大多消失**：同样 6 个窗口，三个池的 bootstrap p<0.05
  都是 **0/6**；top50 只有 2024 窗口 |t|=2.12（p=0.059），沪深300 成分最高 t=1.59（p=0.188）。
  这说明相对沪深300 的正 alpha 主要是**等权/规模/基准错配**（沪深300 是市值加权，
  等权组合天然偏向小盘），**不是个股选择能力**。

> **校准与功效（`h2_results.json` 的 `calibration`）**
>
> **安慰剂/高斯对照**：打乱市场（全 A、2022-12→2024-12 单窗）后 |t|>2 = **0.8%**、λ=**0.704**；
> 同窗真实全 A |t|>2 = **1.5%**、λ=**0.770**；纯高斯噪声过同一管道 |t|>2 = **4.6%**、sd(t)=1.001。
> 也就是说，旧判据的零分布约 5%，打乱市场的 0.8% 是**坏安慰剂**（破坏了 beta 关系），
> 不能当作 alpha 的零分布；真实全 A 的 1.5% 与 λ=0.77 说明**估计噪声主导**，不是 alpha 弱。
>
> **新判据逐窗 bootstrap（B=100，块长 20）**
>
> | 池 | λ 显著窗口数（p<0.05） | 组合 α vs 沪深300 显著窗口数 | 组合 α vs 等权全A 显著窗口数 | λ 功效（5/10/20%） | 共同α功效 vs 沪深300（5/10/20%） |
> |---|---|---|---|---|---|
> | 沪深300成分 | **2/6** | 5/6 | **0/6** | 10% / 34% / 99% | 26% / 61% / 100% |
> | 成交额top300 | **0/6** | 3/6 | **0/6** | 9% / 20% / 93% | 12% / 26% / 70% |
> | 成交额top50 | **0/6** | 5/6 | **0/6** | 7% / 8% / 34% | 9% / 21% / 60% |
>
> **判读**
>
> 1. **横截面 alpha 离散不稳健**：λ 只在沪深300 成分的 2/6 窗口显著（2024、2025），
>    top300/top50 为 0/6；且 λ 的 5%/年功效只有 **7%–10%**，10%/年也只有 8%–34%。
>    因此不能据此说「alpha 弱」，也不能说「alpha 强」——**无法判定**。
> 2. **组合层 alpha 显著，但不是选股能力**：相对沪深300，沪深300 成分 5/6、top50 5/6、
>    top300 3/6 窗口显著；但相对**等权全 A 市场**，三个池都是 **0/6** 窗口显著。
>    这说明相对沪深300 的正 alpha 主要是**等权/规模/基准错配**（沪深300 市值加权），
>    不是个股 alpha。共同 alpha 的 5%/年功效只有 9%–26%，20%/年才到 60%–100%。
> 3. **新判据能区分大信号与噪声**：安慰剂/高斯零分布校准到约 5%；
>    20%/年共同 alpha 在沪深300 成分上功效 100%、20%/年横截面离散 99%；
>    但 5%/年量级上功效不足以支撑「支持/不支持」的二分，只能「无法判定」。
>    **这正是原判据缺的东西：可量化的零分布 + 可量化的功效。**

#### 4.2.4 分级（修订）

| 子命题 | 原分级 | **修订后分级** | 依据 |
|---|---|---|---|
| H2a A 股个股 Beta 主导（R² 中位 ≥0.50） | 不支持 | **不支持** | 可比池 0.200–0.247 « 0.50；R²≥0.5 仅 2.2%–6.8% |
| H2b A 股个股 Alpha 很弱（原判据 \|t\|>2 ≤10%） | 支持 | **无法判定（原「支持」撤回）** | 原判据零假设期望约 5%、安慰剂 0.8%，无判别力；新判据下 λ/τ 不稳健、5%/年功效不足；组合 alpha 显著但相对等权市场消失，归因于基准/规模而非个股 alpha |
| H2c 「Beta 主导」是 A 股特有 | 不支持 | **不支持** | 美股 50 只大市值 R² 中位 0.318 > A 股可比池 |
| H2d A 股个股 R² 低于美股 | 未单列 | **支持（差距减半）** | 0.200–0.247 vs 0.318，差距 0.07–0.12；全 A 口径差距 0.194 |

**要点：**「alpha 很弱」在可比池下**不再被数据支持**——原 5.1% 接近名义 5%，
按新判据只能判「无法判定」，不能判「支持」。这不是把结论从「支持」改成「不支持」，
而是承认**原判据没有能力回答这个问题**；新判据也不足以在 5%/年量级上给出确定答案。
若必须给一个方向：**没有证据支持「Alpha 很弱」这一强表述**；同样也没有证据支持「Alpha 很强」。

### 4.3 H3（一致性检验，不是因果）

样本：70 个月末质押快照（2020-02-28 → 2025-12-31）。

| 关系 | Spearman ρ | n | 置换 p |
|---|---|---|---|
| 中位质押比例变化 vs 未来 20 日回撤 | −0.072 | 69 | 0.553 |
| 中位质押比例变化 vs 未来 60 日回撤 | −0.125 | 69 | 0.307 |
| 高质押（≥30%）占比变化 vs 未来 20 日回撤 | −0.142 | 69 | 0.248 |
| 高质押占比变化 vs 未来 60 日回撤 | −0.181 | 69 | 0.140 |
| 中位质押比例水平 vs 未来 20 日回撤 | −0.055 | 70 | 0.647 |
| 中位质押比例水平 vs 未来 60 日回撤 | −0.020 | 70 | 0.875 |
| 两融周增速 vs 未来 20 日波动 | **+0.184** | 848 | **<0.001** |
| 两融月增速 vs 未来 20 日波动 | **+0.209** | 199 | **0.003** |
| 两融月增速 vs 未来 20 日回撤 | −0.071 | 199 | 0.314 |

**判读**：

- 质押比例变化与后续回撤方向为负（质押上升 → 后续回撤略深），但**全部不显著**（p 0.14–0.87）；
  样本只有 70 个月，且是市场层面聚合，检验功效很低。→ **无法判定，没有支持「质押加杠杆→批量收割」**。
- 两融增速与未来波动正相关（ρ≈0.18–0.21，p<0.01）：杠杆扩张期后续波动更高，
  这与「杠杆放大波动」的机制**一致**，但**也同样与**「波动上升吸引杠杆」**一致**，
  且重叠样本会让显著性偏乐观。**不能据此推断任何主体在「合谋收割」**。
- 「合谋资金 → 高管参与 → 质押 → 收割」是一条**多环节、带意图**的链条；
  本数据只能检验其中两个可观测环节的相关性，**不能检验合谋、意图或因果顺序**。

## 5. 结论分级

| 层级 | 命题 | 分级 | 依据 |
|---|---|---|---|
| H1 | 四类外部变量对沪深300 的**同期**共动「极其贴合」 | **支持（仅同期共动，周频擦线）** | 信息可得周 OOS R² **0.205** / 命中 **67.6%**；月 **0.319 / 73.7%**；相对 0.20 门槛仅 +0.005；同一期间 0.408 含约一半收盘后重叠 |
| H1' | 四类外部变量能**预测**下一期 A 股走势 | **不支持** | 滞后一期 OOS R² −0.051（周）/ −0.114（月），命中 53.7%/42.1%，触发预注册推翻条件 |
| H1'' | 共动来自「全球风险因子」（外币/外股/外汇/外债四类共同） | **不支持** | 信息可得下仅恒生 0.219 ≈ 四因子 0.205；S&P500 0.046、汇率 0.11–0.14、美债 ≈0；日频 lead-lag 显示恒生同一时段、无领先性 |
| H2a | A 股个股 **Beta 主导**（R² 中位 ≥0.50） | **不支持** | 可比池 0.200–0.247（全 A 0.124） |
| H2b | A 股个股 **Alpha 很弱**（原判据 \|t\|>2 ≤10%） | **无法判定（原「支持」撤回）** | 原判据无判别力（零假设 ~5%、安慰剂 0.8%）；新判据 λ/τ 不稳健、5%/年功效不足；组合 alpha 显著但相对等权市场消失 |
| H2c | 「Beta 主导」是 **A 股特有** | **不支持** | 美股大市值对照 R² 中位 0.318 > A 股可比池 |
| H2d | A 股个股 R² 低于美股（同方法、可比池） | **支持（差距减半）** | 0.200–0.247 vs 0.318，差距 0.07–0.12 |
| H3a | 质押比例变化与后续回撤有关 | **无法判定** | ρ 负但不显著（p 0.14–0.87），样本 70 |
| H3b | 两融增速与后续波动正相关 | **支持（相关）** | ρ 0.18–0.21，p<0.01；不可解释为因果 |
| H3c | 「合谋 → 高管 → 质押 → 收割」链条成立 | **无法判定 / 不支持** | 不可因果检验；无合谋/意图/高管行为数据 |

**我认为该说法最站不住的一环（修订后）**：

不是「外部变量与 A 股同期相关」（这部分是真的，恒生尤其强），而是
**从「同期共动」跳到「由外部驱动」，再跳到「可据此判断走势」**。
而且原报告的 0.391 把约一半的收盘后重叠也算进了「贴合」；按信息可得口径真共动只有 **0.205**，
且几乎全部来自恒生（同一交易时段），不是「全球风险因子」。
第二个薄弱环节是 H2 的「Beta 主导」——低 R² 恰恰说明市场因子解释不了大部分个股波动；
第三个是「Alpha 很弱」——原判据没有判别力，不能作为结论依据。

## 6. 限制

1. **对齐与时区（修订）**：周频以各自市场最后一个交易日收盘对齐。同一期间口径下，
   美股周五夜盘发生在周六 04:00 CST，恒生周五 16:00 收盘，均晚于 A 股 15:00——这不是「小时级」，
   而是把周频 R² 削掉约一半（0.408 → 0.205）。信息可得口径按各市场收盘时点截断，
   是「可交易/可预测」的正确口径；整期滞后口径把恒生同一时段的重叠也丢掉，
   因此是**过度保守的下界**（−0.051），不是可交易口径。
2. **样本期**：周频主样本从 2017-03 起（SHIBOR 约束），月频主样本从 2010 起；不同因子可用区间不同。
3. **市场代理**：H2 用沪深300/中证全指作为市场组合，未做 Fama–French 三因子/五因子分解；
   「beta」仅指单因子市场 beta。组合层 alpha 相对沪深300 为正、相对等权全 A 市场大多不显著，
   说明它主要是等权/规模/基准错配，不是个股 alpha。
4. **美国对照**：50 只大市值股票，不是全美股；仅用于「同方法对照」，不能代表美股整体。
5. **质押数据**：月末快照、只含有质押的股票、市场层面聚合；不能做个股层面的质押—回撤检验。
6. **北向资金**：2024-08 后停止披露；含北向的设定只覆盖 2019–2024 的样本外区间。
7. **多重比较**：本报告列出了全部尝试过的设定（10 个原 H1 + 5 个双档 H1 + 逐因子分解 +
   2 个市场代理的 H2 + 3 个 H3 关系），没有做 Bonferroni 等校正；主结论依赖预注册判据，
   不依赖「挑一个最显著的」。新 alpha 判据的 p 值是逐窗 bootstrap，未做跨窗口多重比较校正；
   因此只报「哪些窗口显著」，不把「2/6 窗口显著」当作稳健结论。
8. **数据质量**：A 股池是 baostock 前复权日线，停牌/涨跌停/退市处理按 R9 既定口径；
   极端收益按 |r|>50% 剔除（可能误删真实极端日，但影响极小）。
9. **沪深300 成分幸存者偏差**：用 2026-11-09 当前成分回溯 2018–2026，方向抬高 R² 与 alpha；
   结论「R²<0.50」不受影响，但 0.217/5.1% 应视为**上限**。
10. **流动性排名的窗口**：固定 top300/top50 用 2022–2024 中位成交额，对 2021 窗口含事后信息；
    逐窗排名的稳健性结果（0.200/0.273，6.4%/10.3%）与固定池一致，不改变结论。
11. **alpha 判据的功效**：新判据在 5%/年横截面离散上的功效只有 **7%–10%**；
    在 5%/年共同 alpha 上 **9%–26%**；20%/年才分别到 **34%–99%** 与 **60%–100%**。
    因此「无法判定」不是「证明 alpha 弱」，而是「这段样本 + 2 年窗口不足以区分」。
    这是本报告最重要的限制之一。
12. **未验证项**：`pwsh` 在本 Linux 工作机不可用，仓库的 `tools/check_gates.ps1` 门禁**未能在本机运行**；
    本 PR 的验证以 `pytest` 全量 + 各脚本真实运行输出为准（见第 8 节）。

## 7. 本报告不能证明什么

- **不能证明因果方向**：所有 H1 结果都是同期相关 / 拟合；即使滞后一期显著，也不等于因果。
- **不能证明「A 股由外部驱动」**：信息可得 R² 0.205 只能说明恒生（同一交易时段）与 A 股**共同变动**；
  也可能是第三因素（中国政策、全球风险偏好）同时驱动两者。
- **不能证明可交易预测能力**：信息可得口径接近「可交易」，但 OOS R² 0.205 只是擦线；
  整期滞后口径为负、命中率接近抛硬币。报告没有做交易成本、滑点、容量约束的回测。
- **不能证明「Alpha 很弱」**：原判据无判别力；新判据在 5%/年量级上功效不足。
  同样**不能证明「Alpha 很强」**：组合 alpha 相对沪深300 显著，但相对等权全 A 市场大多消失，
  更像等权/规模/基准错配，不是选股能力。
- **不能证明「合谋」「高管参与」「收割」存在**：本报告没有任何资金账户、股东、高管交易、
  质押逐笔或司法/监管数据；H3 只是两个市场级时间序列的相关性。
- **不能证明「质押加杠杆导致回撤」**：质押与回撤的相关不显著，且样本短、聚合粗。
- **不能证明「Beta 主导 = 没有 alpha」**：低 R² 只说明市场因子解释力低；
  alpha 不显著也可能是检验功效不足，而不是 alpha 不存在。
- **不能外推到其他指数/时段/市场**：结论限于沪深300、2019–2026 样本外区间与本次数据覆盖；
  月频只有 95 个 OOS 点，显著性弱于周频。
- **不能替代监管调查或司法认定**：任何关于市场操纵的判断都需要监管数据与法定程序。

## 附录 B：口径说明

- **OOS R²**：`1 − SSE(model)/SSE(expanding mean)`；预测值来自每期重新估计的扩展窗口；
  扩展均值的预测使用截至上一期的样本，不含当期。
- **方向命中率**：预测与实际同号的比例；剔除 0。
- **DM 检验**：平方损失差，Newey–West（h−1 阶）；报告统计量与双侧正态近似 p 值。
- **ADF**：含常数，BIC 选滞后阶（0–4）；5% 临界值 ≈ −2.86。
- **信息可得（avail）**：对每个 A 股期间末 D，外盘取 `date < D` 的最后一根；窗口左右端同时前移。
- **同一期间（samegrid）**：各外盘按自己的 Period 取最后一根，对齐到 A 股 Period 网格后差分。
- **λ**：`SD(α̂_i) / sqrt(mean(SE_i²))`；**τ**：`sqrt(max(Var(α̂_i) − mean(SE_i²), 0)) × 250`。
- **组合 alpha**：池内个股等权日度再平衡，对市场做带截距 OLS；t 用 Newey–West(5)。
- **残差块 bootstrap**：块长 20 个交易日；同一组合内每只股票独立重采样残差；
  组合层对组合残差重采样。B=100。
