## 0. 结论先行

1. **按 P1 §3.6 的预注册门槛（Y / Z），9 个候选规格没有一个通过。**
   - **Y（扣费年化改善 ≥ +1.5pp）**：最好的是季度容忍带再平衡 **+0.80pp/年**
     （配对日差算术年化；两侧几何年化差为 **+1.20pp**，两种读法都 < 1.5pp。
     NW t = 0.69，该样本 80% 功效的 **MDE = 3.22pp**）——**未检出**，不是「无效」；
   - **Z（maxDD 改善 ≥ 3pp 且年化劣化 ≤ 0.5pp，且必须过等暴露度对照）**：
     `regime_ma200` 的 maxDD 确实低 **5.13pp**，但年化同时 **−1.13pp**（劣化超过 0.5pp），
     且其 ΔmaxDD 只落在等暴露度随机组的 **89 分位**（要求 >95 分位）——
     **不能把「减仓」当成「择时有效」**；
   - 其余候选（风险平价、回撤 trim、估值/资金 tilt）在年化、回撤、对照三项上都不达标。
2. **因此：不提议任何生产变更**（不改 CLI / 决策逻辑 / action）。
3. **若用户需要一个可以立刻执行、且不增加成本的纪律**，本报告推荐
   **方案 A：季度末等权 + ±5pp 容忍带再平衡**（§6.1）。它的点估计是
   +0.80pp/年（配对日差算术；几何 +1.20pp，t=0.69 < MDE 3.22pp）、
   OOS 同号（+2.81pp）、换手与买入持有几乎相同（20.4% vs 17.7%）、
   50bp 赎回费也只多约 0.04pp/年；maxDD 在本实现下不变（刀尖结果，见 §5.2）。
   但必须写清：**这不构成 edge 证据**（< MDE），它是「卫生习惯」，不是 alpha。
4. **方案 B（可选，仅当目标明确是降回撤）：MA200 regime overlay**
   （`sh000300 close < MA200` → 权益暴露 50%）。规格见 §6.2；
   它同时压低收益与回撤，且**未通过等暴露度对照**，只适合纸面试点。
5. **不推荐**：风险平价（用 65–92%/年的换手换来 −1.1~−2.5pp 年化）、
   回撤触发 trim/add（−1.57pp、maxDD 只改善 1.09pp、随机对照 93 分位）、
   估值 tilt（组合 +0.63pp，t=0.45）、资金流 tilt（**样本不足**，见 §5.8）。

## 4. 方法与统计

### 4.1 模拟引擎

`tools/portfolio_lab.py::Sim` 是**权重级**日频模拟：

1. 用当日收益把上一日权重漂移成当日权重；组合收益 = Σ wᵢrᵢ（现金 0）；
2. 执行前一日收盘定下的目标权重（t+1 成交），成本直接从组合价值扣除；
3. 成交后权重 = 目标权重（未成交部分保持原权重并顺延重试）；
4. 记录净值（扣费与毛净值两条）、单边换手、交易资产数、权益暴露。

自检（`selftest`，8 项，合成数据、不触网）覆盖：净值有限性、买入持有唯一建仓与成本等式、
**毛净值 = 各资产净值比的等权均值**（1e-16 误差）、带内不交易、**无前视**
（把未来收益放大 10 倍不影响过去净值）、成本单调性、随机掩码二值性、指标字段完整性。

### 4.2 指标

扣费年化（几何）、maxDD、Sharpe（rf=0）、年化单边换手、再平衡次数（有成交的交易日数）、
平均权益暴露；另报毛年化与**扣费拖累**（净 − 毛）。

### 4.3 统计推断

- **配对差**：候选与基线的日收益差 → 年化差、Newey-West t（lag 20，日频）、双侧 p；
- **MDE（80% 功效、双侧 5%）**：`2.8 × std(日差)/√n × 252`；
- **OOS**：最后 30% 时间（**2024-05-08 ~ 2026-11-11，611 个交易日 ≈ 2.51 年**），
  同一口径重算并检验「与全样本同号」；
- **等暴露度随机对照**：`regime` 用「随机挑选同样多的低暴露月份」，
  `dd_trim` 用「日频 iid 随机减仓、平均暴露匹配」，各 **300 次**（种子 20261113+rep）；
- **maxDD 不确定性**：块重抽（block=20，1000 次）给出基线 maxDD 的抽样分布；
- `n_trials = 9`，不做事后挑选。

### 5.2 基线（买入持有等权）

- 全样本 **+14.80%/年**、maxDD **30.63%**（发生在 **2018-10-18**）、Sharpe 0.63；
  逐年：2019 **+70.5%**、2020 +38.3%、2021 +12.8%、2022 −7.0%、2023 +7.8%、2024 +4.9%、
  2025 +33.8%、2026（至 11-11）−1.9%。
- 块重抽 1000 次的 maxDD 分布：p05 25.7% / 中位 **37.9%** / p95 58.8%。
  实现值 30.6% 低于中位数——**单条路径的 maxDD 数字本身噪声很大**，
  所有「A 比 B 回撤低 5pp」的结论都应先看随机对照（§5.4）。
- **maxDD 计算口径**：`metrics()` 对评估窗内**扣费日净值**取 `max(1 − eq / peak)`，
  峰值含起点、日频、全窗（不是月频、不是 OOS 单算）。它是**单条路径**估计，
  因此对路径微差敏感（见下条）。
- **基线独立复算（V24 / issue #79）**：Hermes 另写一套实现（固定份额 + 建仓成本 +
  新资产次日 1/N 全量重设）得到 **+14.88%/年、maxDD 31.05%**（本报告 +14.80% / 30.63%）。
  差异已定位：本引擎在**评估起点次日（2018-06-21）多做了一次全量重设**——601066 的上市日
  就是评估起点，`available` 在起点当天翻转，被「新资产上线」逻辑当成新资产，于是 `bh_eq`
  多出 2.15% 单边换手、约 0.8bp 成本（`blocked=1`，有成交交易日 9 天 vs 独立实现 8 天）。
  这一次成本沿整条净值路径放大，造成 +0.08pp 年化 / 0.42pp maxDD 的差。
  **不是前视、不是口径错，但其他实现复算时应知道这一条**。
- **`ew_quarterly_band5` 的 maxDD 30.63% 与基线相同是「刀尖结果」，不能当稳健结论**：
  首次季度评审 2018-06-29，601066 权重离 5pp 边界只差 0.52pp（本引擎偏离 4.48pp → 未触发）；
  Hermes 的独立实现在同一时点算出 6.86pp → 触发，整条路径随之改变，
  其季度方案 maxDD 为 **28.73%**（相对其自身基线 31.05% 改善 **−2.31pp**）。
  两种实现都 < Z=3pp，判定不变；但「季度带不改变 maxDD」只应读作
  「**在本实现下**没改变」。

## 6. 推荐 1–2 个方案与明确规格

> **前提**：按 §2.2 门槛，没有候选通过。下面的「推荐」是**执行纪律**层面的建议，
> 不是「有 edge 的证据」；任何生产 action 变更都必须等前向样本或更长的历史。

### 6.1 方案 A（推荐，作为纪律）：季度末等权 + ±5pp 容忍带

| 项 | 规格 |
|---|---|
| 目标权重 | 当日**已成立**资产等权 1/N（股票与场外基金一视同仁） |
| 评审时点 | 每季度最后一个交易日**收盘** |
| 触发 | 仅当某资产实际权重偏离目标 **> 5pp** 时，把**该资产**拉回目标；未越界资产不动 |
| 成交 | 下一交易日收盘；股票按开盘/收盘差计 10bp 滑点，基金按当日净值确认 |
| 成本 | 股票买 13bp / 卖 23bp；基金申赎各 15bp（赎回费提到 50bp 也只多约 0.04pp/年，见 §3.4） |
| 新资产 | 成立次日按 1/N 等权买入 |
| 现金 | 0 收益；不配货基（若配，按 1.3%/年另计） |
| 预期换手 | **20.4%/年**（买入持有 17.7%/年；月度方案 20.5%/年） |
| 证据 | 全组合 **+0.80pp/年**（t=0.69，MDE 3.22pp）；OOS **+2.81pp** 同号；基金袖套 +1.10pp（t=1.18）；maxDD 不变 |
| 判定 | **不构成 edge**（< MDE）；但**不增加换手与回撤**，可作为「防止单一基金膨胀」的纪律 |

选季度而不是月度的理由：两者的点估计与换手几乎相同（+0.80 vs +0.22pp、20.4% vs 20.5%），
季度**评审次数少 3/4**、执行摩擦更低；月度没有表现出额外收益。

### 6.2 方案 B（可选，仅当目标明确是降回撤）：MA200 regime overlay

| 项 | 规格 |
|---|---|
| 信号 | 月末收盘 `sh000300 close < MA200` → 权益暴露 **50%**；否则 100% |
| 调仓 | 仅当暴露档位变化时，下一交易日按**现有相对权重等比例**减/加 |
| 现金 | 50% 部分记 0 收益（货基收益未计，偏保守） |
| 成本 | 同上；预期换手 **57.4%/年**（约 15 次 MA200 档位切换，含 2024 年两次来回） |
| 证据 | maxDD **25.50%**（改善 **5.13pp**）、年化 **14.41%**（**−1.13pp**）、Sharpe 0.72；OOS **−3.04pp** |
| 判定 | **Z 路径不通过**：年化劣化 1.13pp > 0.5pp；且等暴露度随机对照分位 **0.89 < 0.95** |
| 适用 | 只有当用户**明确接受用约 1pp/年的收益换约 5pp 回撤**、且理解它不优于随机减仓时，才做纸面试点 |

A 与 B 的定位不同：A 是「不做事比做事更差」的卫生规则，B 是「拿收益换回撤」的择时规则。
**不要同时上**，也**不要因为 A 便宜就顺手加 B**。

## 10. 限制、风险与变更记录

### 10.1 限制（如实列出）

1. **样本长度**：全组合 **8.394 年**、OOS 2.51 年；Y=+1.5pp 在 10 资产上**不可检出**
   （除样本不足的 `flow_tilt_stock` 外，MDE 均 >3.1pp）。
2. **权重假设**：实仓的真实权重未知，本报告按**等权**建模。用户实际若重仓某只基金，
   所有结果都会变；方案 A/B 的规格不依赖真实权重，但效应量级依赖。
3. **成本假设**：基金赎回费按 15bp；若实际 <1 年为 0.5%（50bp），季度再平衡的额外成本
   实测约 **−0.039pp/年**（§3.4 表格），vsBH 几何差 1.20 → 1.19pp，**不改变任何判定**。
   股票 13/23bp 与 `BacktestConfig` 同值，但未计冲击成本（小资金可忽略）。
4. **现金 0 收益**：regime / trim 的现金部分偏保守；若按货基 1.3%/年，regime 的年化劣化会缩小
   约 0.5pp（暴露 0.81×1.3%），但仍不足以过 Z 的 0.5pp 线且随机对照仍不通过。
5. **累计净值口径**：分红再投的精确性依赖东财累计净值序列；006195 有 108 个缺失日，
   已按「前值估值、当日不可交易」处理，未编造净值。
6. **高波动新基金**：025422/025415 只有 1.17–1.19 年样本，且波动 50–65%；
   它们在 2025-09 之后的加入改变了组合路径，**近一年数字不可外推**。
7. **等暴露度对照**只对 `regime` / `dd_trim` 做了；其余候选不改变暴露，不适用该对照。
   `riskparity` 的权重差异用「随机置换权重」控制未做（会增加 300×9 次模拟）——**未验证**。
8. **T+1 与涨跌停**：股票已按 `can_buy/can_sell` 逻辑阻塞停牌/无净值交易并顺延 20 日；
   基金按「t+1 净值确认」近似，未计赎回款 T+2~T+4 到账的现金拖累。

### 10.2 变更记录（实现修正；候选参数未改）

初版运行暴露了 3 个实现缺陷，修正后才产出本报告全部数字。**候选规格与参数没有因结果而改**，
但以下修正发生在已看到部分输出之后，如实记录：

1. **统一建仓与新资产上线**：初版只有买入持有会加入新资产，导致其他候选漏买、
   与基线不可比；改为引擎统一在评估起点等权建仓、新资产成立次日按 1/N 买入。
2. **成交重试**：初版对停牌/无净值的成交会把剩余权重永久留在现金
   （例如 006195 成立日无净值 → 1/6 现金卡了 10 个月）；改为最多顺延 20 个交易日重试。
3. **回撤 trim 的 episode 锁**：初版在恢复满仓后若仍在 −10% 以下会立即再次减仓（级联）；
   改为每个回撤 episode 只减一次、回到 −5% 内才重新武装。

每次修正后都重跑 `selftest`（8/8 通过）与全部分析；`docs/` 与代码在同一 commit 中，
结果可由 §9 的命令复现。
