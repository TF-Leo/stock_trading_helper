### 2.2 组合构建（全部候选同一套）

- long-only、等权 top-30、**非重叠**调仓：决策日 d 收盘算分，t+1 开盘买入，
  持有 H 个交易日后（d+H+1）开盘卖出；下一窗在 d+H 收盘决策。
- **持仓延续（carry-over）**：同一只票在相邻两窗都被选中时不清仓再买，
  只对「新增 / 卖出」的部分计成本；否则会高估持续型策略的成本。
- 等权按 top-30 槽位计；买不进的票（涨停/停牌）该槽位**留现金**，
  不摊给其他票；卖不出的票顺延到下一可成交日（上限 20 个交易日）。
- 未做：盘中成交、部分成交、融券/做空、冲击成本随规模变化。

### 3.1 取数

- **票池**：沪深 300 **当前成分**，`baostock.query_hs300_stocks()`，

  **单一数据源**，不存在 R5 的腾讯/baostock 混源问题。
- **指数**：`sh.000300` 日线，作为沪深 300 基线。
- **取数区间**：2016-06-01 ~ 2026-11-12（预留 252+ 根预热）。
- **评估区间**：2018-01-03 ~ 2026-11-12；H=1 共 2148 个交易日。
  （H=120 的最后一个窗结束更早，因需完整 120 日持有期。）

取数结果：成功 300/300，失败 0 只（如失败，逐票记录在
`evidence/p2/data/fetch_meta.json`）。每票行数 min 228（新上市）、
中位 2537；区间内缺失收盘 9.5%（停牌/上市前，按不可成交处理）。
环境：Python 3.14.4 / pandas 3.0.1 / numpy 2.5.4 / baostock 0.9.4。

### 3.2 幸存者偏差（必须与结论一起读）

票池是 **2026-11 的当前成分**，不是历史时点成分。退市/被调出的标的不在池内，
因此：

- 所有候选、等权基线、随机对照都**共享**这份幸存者偏差；
- 「策略 vs 等权 / 随机」是**同池相对比较**，可以回答「选股/择时是否比
  不做选择更好」；
- **绝对收益不可当作可投资业绩**。本报告用真实沪深 300 指数给出量级：
  当前成分等权年化 14.26% vs 指数 -0.13%，差 14.4pp/年
  （其中含约 +2%/年的分红口径差；其余主要是幸存者偏差）。
- 任何「低回撤」结论也要打折：幸存者不仅收益高，回撤也更小
  （等权 maxDD 27.6% vs 指数 45.6%）。

### 3.3 样本量与功效

| H | 独立窗 K | 说明 |
|---:|---:|---|
| 1 | 2,147 | 每日一个非重叠窗 |
| 5 | 429 | |
| 20 | 107 | |
| 60 | 35 | |
| 120 | **17** | 8.9 年只有 17 个独立持有期 |

组合层面的一年只有 252/H 个**独立**观测；日频净值虽然长，但持有期内高度自相关，
不能拿来当独立样本。因此：

- H=120 的 17 个窗在 80% 功效、α=0.05 下的年化 MDE 约 **25–30pp**；
  H=20 约 **13–34pp**；H=60 约 **25–30pp**；H=1/5 约 **20–24pp**
  （随组合波动变化，见 §5.4）。
- 要检出 **10pp/年** 的 edge，在组合年化波动 ~28% 时，需要约
  `(2.8×0.28/0.10)²×252 ≈ 1.5 万交易日 ≈ 60 年`级别的样本；
  降低波动或提高持仓分散度比换持有期更能改善功效。
- 因此**本轮对任何候选都不能做「存在/不存在 edge」的强结论**；
  能下的结论是「在当前样本与成本下，没有候选达到可推荐标准」。

## 4. 方法与口径

### 4.1 时点与成交

- **无前视**：所有打分只用 d 日收盘及以前的数据；t+1 **开盘**成交
  （与 `engine.exec_price='next_open'` 一致）。
- **T+1**：信号日与成交日分离，见上。
- **涨跌停不可成交**：涨停不买、跌停不卖；阈值与
  `decision/instrument.py::get_price_limits` 一致（`1 ± (limit−0.001)`），
  ST 用 5%。停牌（`tradestatus=0`）按不可成交处理。

### 4.2 成本（复用生产口径）

| 项 | 单边 | 说明 |
|---|---:|---|
| 佣金 | 3bp | `BacktestConfig.commission_rate` |
| 滑点 | 10bp | `BacktestConfig.slippage_rate` |
| 印花税 | 卖出 10bp | `BacktestConfig.stamp_duty`（生产引擎同值；2023-08 后实际 5bp，故本轮偏保守） |
| **买入合计** | **13bp** | |
| **卖出合计** | **23bp** | |

成本在每次「新增/卖出」时按名义金额计入；持仓延续不重复计费。
若把印花税改为 5bp，按年换手 T 估算，净年化大约改善 `T × 5bp`
（H=120 约 +0.1pp、H=20 约 +0.2–0.5pp、H=5 约 +1pp、H=1 约 +3pp），
不改变本报告排序。

### 4.3 基线

1. **等权买入持有（EW）**：当前 300 只成分，等权，每 20 个交易日再平衡回等权；
   同成本、同涨跌停/停牌规则。它是「什么都不选」的对照。
2. **沪深 300 指数**：`sh.000300` 价格指数（不含分红），无成本。
3. **等暴露度随机组（两种）**：
   - `iid`：每个再平衡窗随机抽 **与候选相同数量** 的票（候选持有 0 只 = 现金）；
   - `turnover`：在上一窗随机组合中随机保留 `n−n_bought` 只，再随机补
     `n_bought` 只新票 —— 同时匹配暴露度与换手。
   每种 500 次重抽（P1 计划 §3.6.4 要求 ≥200；本轮为 500）。
   随机组与候选**共享同一票池/幸存者偏差**，所以它检验的是「选股/择时」，
   不是「这个池子好不好」。

### 4.4 统计

- **主检验**：非重叠窗收益的 t 检验（单侧），`p_period`。
  同时报日频 Newey-West t（`nw_t`）作参考；后者对长持有期会因自相关偏乐观，
  **不用于判定**。
- **DSR**：Bailey & López de Prado (2014)，`n_trials=13`；分别报日频与
  非重叠周期口径。周期口径先按 `sqrt(H_i/H_j)` 把各试验的 Sharpe 统一到
  本候选的 H 期，避免长短周期混算虚增 SR0。
- **Bonferroni**：`p_period × 13`，α=0.05。
- **块 bootstrap**：循环块（块长=max(H,5)）1,000 次，给年化与 Sharpe 的 95% CI。
- **Walk-forward**：3 年训练 + 1 年测试滚动；每个测试年选**训练期 Sharpe 最高**
  的候选，交易下一年。参数本身全部冻结，所以这不是「调参」，而是检验
  「选族/选尺度」本身是否稳定。2026 年不足 1 年，不纳入。

### 4.5 前置自检

`python tools/strategy_lab.py selftest` —— 9 项合成数据校验：
T+1 调度、36bp 成本、涨停不可买、跌停顺延、未来数据不影响当日选择、
随机组、DSR 单调性、滚动分位与 `context_ic._rolling_percentile` 同值、
年化/回撤定义。结果：**9/9 PASS**。

## 6. 推荐试点方向（仅纸面，不是生产建议）

**严格按 §2.3，推荐进入生产的方向：无。** 下面 1–2 个方向只用于
**前向纸面取样**，目的是积累独立样本，不是「有 edge 的证据」。

### 方向 A（首选）：横截面 12-1 动量，H=120

| 项 | 规格 |
|---|---|
| 票池 | 实盘用**当日**的沪深 300 成分（point-in-time）；本回测只有当前快照，故结果含幸存者偏差 |
| 过滤 | 剔除 ST、停牌、上市不足 252 个交易日的票 |
| 信号 | `mom_12_1 = close[t−21] / close[t−252] − 1`，降序 |
| 组合 | long-only、等权 top-30、无杠杆 |
| 调仓 | 每 120 个交易日；d 收盘算分，d+1 开盘成交 |
| 出场 | 持有满 120 个交易日开盘卖出（无止损/止盈） |
| 成本 | 买入 13bp、卖出 23bp（含印花税 10bp） |
| 约束 | T+1；涨停不买、跌停不卖；买不进留现金 |
| 预期换手 | ~110–160%/年 |
| 监控 | 每窗记录信号/成交/净值；至少 12–24 个月；与回测的偏离 >2σ 或前向 Sharpe<0 则停 |

**证据状态**：扣费年化 22.64%、Sharpe 0.84、OOS 45.66%，
但 K=17、MDE 29.9%、DSR_period 0.83、Bonferroni 0.116 ——
**不足**，仅作前向取样。

### 方向 B（备选，且与 A 高度相关）：趋势/Donchian，H=120

| 项 | 规格 |
|---|---|
| 过滤 | `close > MA200`；剔除 ST/停牌 |
| 信号 | `close / rolling_max(close,55) − 1`，降序（越接近 55 日新高越前） |
| 组合/调仓/成本/约束 | 同方向 A（top-30、H=120、T+1、涨跌停、13/23bp） |
| 预期换手 | ~160%/年 |

**证据状态**：年化 16.86%、Sharpe 0.77、OOS 34.20%；
随机组 p=0.222（iid）/ 0.214（换手匹配），**未跑赢随机组**，
且 K=17、DSR/Bonferroni/功效均不达标 —— **不足**。

> A 与 B 都是「买近期强势股」，相关性高；若试点，只选 A，避免重复下注。

## 8. 下一步

1. **不要继续在样本内找参数/换因子。** 本轮 13 个候选已覆盖 5 个持有期、7 个族；
   R3/R5 也证明加数据源没有正向增量。继续试只会增加 `n_trials`、降低可信度。
2. **若要做生产级验证，先解决幸存者偏差**：取得**历史时点**的沪深 300 成分
   （当前 baostock/akshare 只有当前快照）。在这之前，任何「年化 X%」都只能
   作为**同池相对比较**，不能作为收益承诺。
3. **前向纸面取样**（方向 A）：至少 12–24 个月，每 120 个交易日一窗；
   记录信号、成交、净值、成本。前向样本每 2 年只增加 4 个独立窗——
   这是长持有期的固有代价，不能靠日频净值「补」样本。
4. **若想提高功效**：降低组合波动（更多持仓、波动率目标、与低波组合叠加），
   或在可接受的相关性下并行多个不重叠的族；单纯换持有期不改变
   `MDE ≈ 2.8 × σ_ann × sqrt(252/T)` 的量级。
5. **成本敏感性**：把印花税从 10bp 调到 5bp 后，H=1 与 MR 仍为负
   （不会翻正），H=5 略改善，H=120 几乎不变。建议在真金白银前先做
   容量/滑点压力测试。

## 10. 限制与风险（如实列出）

| 风险 | 说明 |
|---|---|
| **幸存者偏差** | 当前成分池，退市/调出不在内；等权 14.26% vs 指数 -0.13% 的 14.4pp/年 就是量级。相对结论（vs EW/随机）可信，绝对收益不可投资 |
| **样本长度** | H=120 只有 17 个独立窗；所有候选年化 MDE >10pp。**不能**据此判定「有/无 edge」 |
| **单一价格源** | 全部 baostock qfq；无腾讯对照。R5 已实测两源收益等价（最大差 3.5e-6），但本轮未重复该对照 |
| **基准口径** | 沪深 300 为**价格指数**（不含分红）；等权为 qfq 总收益。二者差约 2%/年，已在 14.4pp 中说明但无法完全分离 |
| **成本假设** | 印花税按生产引擎 10bp（实际 5bp），偏保守；滑点固定 10bp，未建模规模/冲击 |
| **涨跌停近似** | 用 qfq 价格与 `prev_close` 判限价；除权日复权因子变化可能造成个别误判（量级很小） |
| **ST 历史** | 依赖 baostock `isST`；早期缺失按非 ST 处理 |
| **组合简化** | 等权、无部分成交、无盘中、无融券；carry-over 假设权重可无成本回到 1/N（漂移成本未计） |
| **多重检验** | 13 个候选、两种随机对照；Bonferroni/DSR 已计 13 trials，但随机对照的 p 值是诊断量，未再做 26 重校正 |
| **walk-forward** | 只选族，不调参数；测试年 2021–2025，2026 不足一年未纳入 |
| **随机组** | 与策略共享幸存者池，故只能检验选股/择时，不能检验池子本身 |
