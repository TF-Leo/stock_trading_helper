## 0. 结论先行

| 上下文 | X 路径：加权 Δ 命中率 | 95% CI（cluster bootstrap） | p（聚类） | n_clusters | OOS 同号 | **X 判定** |
|---|---|---|---|---|---|---|
| P1-1 估值（`pb_pct_3y` ≤ 当日池内中位数） | **−1.46pp** | [−2.77, −0.14] | 0.030 | **8,704** | 是 | **未达到**（方向为负） |
| P1-2 资金面（`flow_net_20d_pct` > 0） | −1.59pp | [−4.80, +1.36] | 0.278 | **599** | **否** | **样本不足** |
| P1-3 指数 regime（`index_label` ≠ Bear） | **−2.16pp** | [−3.86, −0.47] | 0.008 | **9,649** | 是 | **未达到**（方向为负） |

**没有任何一项达到 X 门槛**（Δ ≥ +3pp 且聚类 p<0.05 且 OOS 同号且 n_clusters ≥ 2,500）。
但与 R3 相比，**判定理由从「样本不足」变成了「方向为负」** —— 这是本轮最重要的变化：

1. **样本量这一关，估值与 regime 已经过了。** 8,704 / 9,649 个「票 × 季度」聚类，
   远超 §3.6.6 的 2,500 下限；实测 MDE 分别为 **2.00pp / 2.62pp**，都已低于 X=3pp。
   也就是说，**如果效应真的存在 3pp，本样本有 80% 以上的把握能检出**。现在观测到的是
   负号，且 CI 上界也压在 0 以下（估值 −0.14pp、regime −0.47pp）—— 这是**可下结论的否定**，
   不是「数据不够」。
2. **资金流仍然样本不足**：只有 599 个聚类（MDE≈9.11pp），且 OOS 反号。
   即便按理论上限 1,196 聚类/年，达到 2,500 个也需要 **约 2.1 年**、达到 4,318 个需 **3.6 年**，
   且必须真实前向（新浪 120 日上限决定了无法回补历史）。
3. **实测 ICC = 0.2754，比 R4 假设的最坏情形 0.20 还高 38%。** 这意味着 §3.6.6 里
   按 ICC=0.20 推出的「2,500 聚类」**偏乐观**；按实测 ICC 重算，X=3pp 在 80% 功效下
   需要 **3,097–3,829 个聚类**（视分组比例）。本轮估值/regime 的聚类数仍高于该值，
   所以上面的否定结论成立；但**未来任何「刚好 2,500 聚类」的样本都不足以判定**。
4. **加权与等权口径在估值上符号相反**（加权 −1.46pp vs 等权 **+5.07pp**），
   本报告 §4.3 用「按聚类大小分层」定位到机制：这是**聚类大小混杂（Simpson 型）**，
   不是某个口径算错。两个口径都必须报，且**加权口径是产品口径**（买点越多影响越大）。

## 3. 方法（与 R4 §3.6.2 逐条对应）

| 项 | 本轮实现 |
|---|---|
| 分析单位（点） | 预注册 3 策略的买点并集（94,928 个） |
| 标签 | `r_{d,20} = open_{d+1+21}/open_{d+1} − 1`；命中 = `r > 0`（与 R3 同一开盘口径） |
| 分组 | 每买点按**当日可得**的上下文阈值分「有/无」；估值用**当日池内横截面中位数**（as-of） |
| **统计单位（聚类）** | **「票 × 自然季度」**；同一票同一季度内所有买点算 1 个聚类观测 |
| 聚类内统计量 | 命中率；权重 = 聚类内买点数（加权口径）+ 等权口径，**两者都报** |
| 主检验 | cluster bootstrap（1,000 次，**按票分层**重抽聚类）+ Welch t（聚类级标准误） |
| 附加检验 | 非重叠子样本 t（每票每 2 个季度取 1，§3.6.7 第 4 条）；OOS = 最后 30% 时间 |
| ICC | **实测**：单因素 ANOVA 矩估计 `ICC = (MSB − MSW)/(MSB + (m0−1)·MSW)` |
| 功效 | `MDE = z·√(se_yes² + se_no²)`，`z = 2.8016`（80% 功效，双侧 α=0.05） |

**X 判定的四条**（§3.6.3）：Δ ≥ 3pp、聚类 p<0.05、OOS 同号、n_clusters ≥ 2,500。
本报告额外报告 Bonferroni 阈值（3 个门槛 → α=0.0167）作为参考；由于本轮**没有任何
Δ 为正**，校正不改变结论。

## 4. 主结果：买点分层（票 × 季度聚类）

### 4.1 总体

```
买点 94,928 个（299 只，2018-01-05~2026-10-14，8.77 年）
20 日命中率 48.46%，均值 +1.43%
聚类（票 × 季度）总数 9,873；每聚类买点 中位 9.0、均值 9.6、最大 35
实测聚类内相关 ICC = 0.2754（m0 = 9.61）
```

**实测 ICC = 0.2754**，高于 R4 假设区间 0.05–0.20 的**上界**（0.20）约 38%。
每聚类买点中位数 **9.0**（R4 估算的 m≈10 接近，但 ICC 明显更高）。

### 4.2 三个门槛的完整结果

**P1-1 估值（`pb_pct_3y` ≤ 当日池内中位数，覆盖 90.3% 买点）**

```
点级：有 40,031（48.41%） vs 无 45,719（49.87%），Δ=-1.46pp  p=2.1e-05
聚类：n_clusters=8,704（有 5,251 / 无 5,622），每聚类买点中位 9.0
加权 Δ=-1.46pp  95%CI=[-2.77, -0.14]pp  p_boot=0.030  p_welch=0.041  t=-2.04
等权 Δ=+5.07pp  p=4.0e-14        实测 ICC=0.2740  DEFF=3.19
OOS（2024-08-22 起）：Δ=-0.57pp，n_clusters=2,818，同号=是
非重叠子样本（每 2 季度取 1）：Δ=-1.13pp  t=-1.13  p=0.259（k=2,704/2,883）
MDE（当前聚类数）=2.00pp
判定：未达到 —— 方向为负（Δ=-1.46pp）
```

**P1-2 资金面（`flow_net_20d_pct` > 0，覆盖仅 3.4% 买点）**

```
点级：有 2,188（42.28%） vs 无 994（43.86%），Δ=-1.59pp  p=0.402
聚类：n_clusters=599（有 466 / 无 414），每聚类买点中位 4.0
加权 Δ=-1.59pp  95%CI=[-4.80, +1.36]pp  p_boot=0.278  p_welch=0.626  t=-0.49
等权 Δ=-11.35pp  p=6.3e-05       实测 ICC=0.3245  DEFF=1.97
OOS（2026-09-04 起）：Δ=+7.49pp，n_clusters=402，同号=否
非重叠子样本：Δ=-6.06pp  t=-1.56  p=0.119（k=314/287）
MDE（当前聚类数）=9.11pp
判定：样本不足 —— n_clusters=599 < 2,500（MDE≈9.11pp）、方向为负、聚类 p 不显著、OOS 反号
```

**P1-3 指数 regime（`index_label` ≠ Bear，覆盖 99.1% 买点）**

```
点级：有 86,091（48.31%） vs 无 7,988（50.48%），Δ=-2.16pp  p=2.2e-04
聚类：n_clusters=9,649（有 9,494 / 无 3,720），每聚类买点中位 9.0
加权 Δ=-2.16pp  95%CI=[-3.86, -0.47]pp  p_boot=0.008  p_welch=0.021  t=-2.31
等权 Δ=-9.17pp  p=2.2e-29       实测 ICC=0.2747  DEFF=3.20
OOS（2024-05-24 起）：Δ=-3.80pp，n_clusters=3,096，同号=是
非重叠子样本：Δ=-2.38pp  t=-1.83  p=0.067（k=4,772/1,935）
MDE（当前聚类数）=2.62pp
判定：未达到 —— 方向为负（Δ=-2.16pp）
```

> **「有 / 无」的聚类数之和大于 n_clusters**（如 regime 的 9,494+3,720=13,214 > 9,649），
> 因为同一「票 × 季度」在门槛两侧都可能出现买点（有的买点满足门槛、有的不满足），
> 两侧各算各的聚类。n_clusters 报的是**该门槛有定义的并集**（§3.6.7 第 3 条：
> 同一聚类内不重复计数，但不跨分组去重）。

### 4.3 加权与等权为什么反号（Simpson 型混杂，不是算错）

估值门槛两个口径符号相反（加权 −1.46pp、等权 +5.07pp）。按聚类内买点数分层后机制很清楚：

| 买点/聚类 | 有：聚类数 | 有：等权 | 有：点权 | 无：聚类数 | 无：等权 | 无：点权 |
|---|---|---|---|---|---|---|
| 1–3 | 1,317 | 0.550 | 0.510 | 1,086 | 0.302 | 0.314 |
| 4–7 | 1,574 | 0.430 | 0.427 | 1,665 | 0.368 | 0.374 |
| 8–12 | 1,478 | 0.472 | 0.475 | 1,842 | 0.491 | 0.497 |
| 13+ | 882 | 0.517 | 0.522 | 1,029 | 0.589 | 0.596 |

* 在**小聚类（1–3 个买点）**里，「便宜」组命中率显著更高（0.550 vs 0.302）——
  这类季度买点稀少，通常是**震荡/下跌后首次触发**；
* 在**大聚类（13+）**里方向**相反**（0.517 vs 0.589）—— 买点密集的季度通常是
  **趋势行情**，此时「便宜」反而意味着买在下跌趋势里。
* 等权口径给每个聚类同等权重，小聚类数量多、且优势大 → 等权为正；
  加权口径按买点数计权，大聚类主导 → 加权为负。

**结论**：产品口径是**加权**（买点越多，该季度对实际交易的影响越大），
所以 X 判定用加权；等权只作为「不同季度被同等对待时」的对照，不能替代主口径。
这也说明 §3.6.2 要求「两个口径都报」是必要的 —— 只看一个会得出相反结论。

regime 门槛同样存在这一机制（小聚类 0.254 vs 0.525；8–12 个买点的聚类 0.467 vs 0.545），
但方向一致（都为负），所以不存在符号冲突。

## 5. 实测 ICC / 聚类数与功效预算

### 5.1 实测值（不得沿用 R4 估算）

| 项 | R4 估算 | **本轮实测** |
|---|---|---|
| ICC | 0.05 / 0.10 / 0.20（区间） | **0.2754**（全样本）；分门槛 0.274 / 0.325 / 0.275 |
| 每聚类买点数 m | ≈10（推导） | **中位 9.0**、均值 9.6、最大 35 |
| DEFF = 1+(m−1)·ICC | 1.45 / 1.91 / 2.81 | **3.19 / 1.97 / 3.20**（分门槛） |
| 聚类总数 | 3,168 上限（未记录） | **9,873** |
| 「票 × 季度」槽位利用率 | — | 9,873 / (299×35) = **94.3%**（35 个季度几乎全部有买点） |

**实测 ICC 高于 R4 最坏假设，意味着 R4 的样本量门槛偏松。** 按 `SD_c = √(p(1−p)/m·DEFF)`
重算（p=0.4966、m=9.0、ICC=0.2754 → DEFF=3.19 → SD_c≈0.299），X=3pp 在 80% 功效下
需要 `(2.8016×0.299/0.03)² × 4 ≈ 3,113` 个等分聚类。**建议把 §3.6.6 的最小样本从
2,500 上调到 3,100–3,900**（含分组不平衡余量）。

### 5.2 本轮功效预算（用实测 SD/ICC 反推，不用 R4 假设）

| 门槛 | 当前聚类数 | MDE（当前） | 按实测聚类 SD 需 | 按实测 ICC 模型需 | 门槛窗口 | 聚类/年（封顶后） | 折算年份 |
|---|---|---|---|---|---|---|---|
| 估值 | 8,704 | **2.00pp** | 3,869 | 3,097 | 2019-01-10~2026-10-14（7.76 年） | 1,122 | **3.4 / 2.8 年** |
| 资金流 | 599 | **9.11pp** | 5,527 | 4,318 | 2026-06-17~2026-10-14（0.33 年） | **1,196（封顶）** | **4.6 / 3.6 年** |
| regime | 9,649 | **2.62pp** | 7,345 | 3,829 | 2018-04-02~2026-10-14（8.53 年） | 1,131 | **6.5 / 3.4 年** |

> **年产量必须按「该门槛有定义的窗口」算，并按理论上限封顶。**
> 资金流窗口只有 0.33 年（120 个交易日）却跨 3 个日历季度；若除以全样本 8.77 年
> 会得到 68 聚类/年（低估 17 倍），若按 0.33 年裸除会得到 1,839 聚类/年（超过
> 4 季度 × 299 只 = 1,196 的理论上限）。本报告按 **min(聚类数/窗口年数, 4×票数)**
> 取 1,196，这是「满仓运行」的乐观值 —— 实际资金流只有 120 日窗口，每年最多
> 产生 4×299 ≈ 1,196 个聚类，**达到 4,318 个至少需要 3.6 年真实前向**。

**关键读数**：

* 估值与 regime 的 **MDE 已低于 X=3pp**（2.00pp / 2.62pp）→ **当前样本足以检出 3pp 效应**，
  所以负号结论是可下的，不是「功效不足」。
* 资金流 MDE 9.11pp ≈ 3pp 的 3 倍 → 当前样本**连方向都判不了**（OOS 还反号）。
  即便按乐观的 1,196 聚类/年，也要 **3.6–4.6 年**；这是四条路径里最慢的一条。
* 「折算年份」是**线性外推**（假设未来聚类产生速率与窗口内相同），仅用于说明量级。

### 5.3 若仍要推进，可行路径（按性价比排序）

1. **不要指望资金流回补历史**。新浪备胎 120 日上限是硬约束，东财 `push2his` 本轮整域不可达。
   唯一路径是 `tools/forward_log.py` 每日落盘 + 20 个交易日结算，积累到 ≥3,100 个
   「票 × 季度」聚类 —— 300 只池约 **2.6–3.6 年**（按理论上限 1,196 聚类/年）。
   这是**唯一诚实的路径**。
2. **估值/regime 若要「翻案」，唯一可能是换门槛定义**（例如用分位数阈值而非中位数，
   或限制在特定 regime 内）。但这属于**新假设**，必须重新预注册并登记 `n_trials`，
   不能拿本轮同一份数据反复试到显著（§3.6.7 第 2 条）。
3. **组合层面 Y/Z 路径未做**。本轮只跑 X 路径；`pb_cheap` 的 maxDD 效应
   （见 §6.1）仍需 §3.6.4 的**等暴露度随机对照**（≥200 次重抽、逐票匹配笔数），
   否则无法区分「选得好」与「买得少」。
4. **缩短持有期到 5 日**可把非重叠区间数 ×4，但会改变产品语义，需单独预注册。

## 6. 与 R3（`docs/P1_EVIDENCE_V1.md`）的对比

### 6.1 点级 Δ 的变化（同口径，可对读）

| 门槛 | R3（99 只） | **R5（299 只）** | 变化 |
|---|---|---|---|
| 估值 `pb_cheap` | −0.57pp（p=0.317） | **−1.46pp（p=2.1e-05）** | 方向一致，**显著性大幅提高**（样本 ×3） |
| 资金 `flow > 0` | −5.93pp（p=0.068，n=972） | −1.59pp（p=0.402，n=3,182） | 方向一致，幅度收窄、仍不显著 |
| regime `≠ Bear` | −2.10pp（p=0.041） | −2.16pp（p=2.2e-04） | **方向与幅度几乎不变**，显著性提高 |

**结论的方向全部与 R3 一致**（三项都为负）。R4 §3.6.8 曾用 DEFF 近似指出
R3 的 `index_label`「聚类后 p 会变 0.09–0.22、失去显著性」；**本轮实测推翻了这个近似**：
在 9,649 个聚类、实测 ICC=0.275 下，聚类 p=0.008，**仍然显著为负**。
R4 的近似方向没错（点级 p 确实偏乐观：0.0002 → 0.008，放大 40 倍），
但它预测的「变得不显著」不成立 —— 因为 R4 假设 DEFF≤2.81 而实测是 3.20，
且样本从 31,466 涨到 94,079 个买点。

### 6.2 稳健性：只用腾讯源（剔除 baostock 补齐的 57 只）

```
来源过滤：299 只 → 242 只
买点 79,583 个，聚类 8,249，实测 ICC=0.2732
估值：加权 Δ=-1.04pp  CI=[-2.46, +0.37]  p=0.148  等权 +5.31pp  OOS 反号  判定：未达到
资金：加权 Δ=+0.72pp  CI=[-2.68, +4.09]  p=0.648  等权 -9.74pp  OOS 同号  判定：样本不足（489 聚类）
regime：加权 Δ=-2.96pp  CI=[-4.78, -1.17]  p=0.002  等权 -9.87pp  OOS 同号  判定：未达到
```

* **regime 的负效应在单源子样本里更强**（−2.96pp vs 全样本 −2.16pp），方向稳定；
* 估值与资金流在子样本里变得不显著，但**符号方向与全样本一致**（估值 −1.04pp、
  资金 +0.72pp 是唯一例外，其 CI 跨 0 且聚类数不足，不能解读）；
* 说明换源（腾讯→baostock）**没有制造结论**，全样本结论不依赖 baostock 补齐的票。

### 6.3 policy 回放（v1 口径，供 Y/Z 路径参考，**不是** X 判定依据）

```
not_bear: 窗口 2018-04-02~2026-11-12（中位 2090 根），交易 19142→18142，
          年化 +0.71%→+0.29%（改善 104/299 票），maxDD 39.61%→39.62%（改善 101/299 票）
pb_cheap: 窗口 2019-01-10~2026-11-12（中位 1900 根），交易 19142→7120，
          年化 +0.84%→+0.11%（改善 124/297 票），maxDD 39.88%→20.85%（改善 239/297 票）
flow_positive: 未回放 —— 该门槛有定义的窗口不足 300 根
```

`pb_cheap` 的 maxDD −19.03pp 看起来达到 Z=3pp，但它伴随**交易数从 19,142 砍到 7,120
（保留 37.2%）**，且年化同时下降 0.73pp。按 §3.6.4，**没有等暴露度随机对照就不能作为
降回撤证据** —— 本轮**未做**该对照，因此 Z 路径**未验证**（不是「不通过」，是「未做」）。

| 项 | X 判定 | 依据 | 建议 |
|---|---|---|---|

**本轮没有任何一项达到 X 门槛**，因此**不提出任何 action 变更**。

## 8. 本轮修掉的真实缺陷（记录，避免重演）

| # | 缺陷 | 发现方式 | 修正 |
|---|---|---|---|
| 1 | `--reuse-panel` 读 CSV 时 `code` 被 pandas 推断成整数（`000858`→`858`），`_load_price("858")` 找不到文件，**78 只票被静默跳过**（299→221） | 复核买点数与面板数不一致（69,474 vs 94,928） | `dtype={"code": str}` + `zfill(6)`；并加「进入面板但无买点」的显式告警 |
| 2 | baostock 停牌日返回**空字符串**（非 NaN），`astype(float)` 抛 `could not convert string to float: ''`，导致 2 只票取数失败 | 日线补齐日志里的 FAIL | `pd.to_numeric(errors="coerce")` + 丢弃无 OHLC 的行（停牌日无有效价格） |
| 3 | baostock 单进程多会话并发会互相踢下线（`10001001 用户未登录`），导致 47/57 只补齐失败 | 补齐日志 | 改为**单会话 + 掉线自动重登**；`fetch` 的日线备胎与估值共用同一会话顺序执行 |
| 4 | 两个 `fetch` 进程并发抓腾讯，请求速率翻倍，正是限流触发条件 | 进程列表自查 | 保留一个进程；`--batch-size/--batch-pause/--cooldown` 显式化 |
| 5 | `_x_verdict` 把所有 Δ<3pp 都写成「Δ<3pp」，掩盖了「方向为负」这一更强的结论 | 读输出时发现 | 区分「方向为负」与「幅度不足」 |
| 6 | 功效预算用**全样本跨度**（8.77 年）折算聚类年产量，把资金流的 0.33 年窗口低估 17 倍（68 vs 1,196 聚类/年），年份被高估到 80 年 | 复核「资金流 120 日怎么可能产出 68 聚类/年」时发现 | 改为按**该门槛有定义的窗口**计算，并按 `4 × 票数` 封顶 |

## 9. 遗留风险与限制（如实列出）

| 风险 | 说明 |
|---|---|
| **幸存者偏差** | 池子 = 2026-11-11 的沪深 300 当前成分；退市/调出标的不在池内。所有结论读作 current-constituent |
| **两源混用** | 57 只用 baostock 前复权补齐（腾讯限流）。已实测收益率等价（最大差 3.5e-6）并给单源稳健性（§6.2），但**价格水平不同**，任何涉及绝对价位的指标都不可跨源比较 |
| **资金流仅 120 日、单一口径** | 东财主力口径完全无数据；结论只适用于新浪总净流入 |
| **资金流 OOS 反号** | 最后 30%（2026-09-04 起）Δ=+7.49pp，与全样本 −1.59pp 相反 —— 这正是「样本不足」的直接证据 |
| **实测 ICC 高于 R4 假设** | 0.2754 > 0.20，说明 §3.6.6 的 2,500 聚类门槛偏松，建议上调到 3,100–3,900 |
| **非重叠子样本 t 与聚类 p 不一致** | 估值 t=−1.13（p=0.26）、regime t=−1.83（p=0.067），而聚类 bootstrap p 分别为 0.030 / 0.008。原因是按季度抽稀后样本量减半、且 t 用正态近似；**三重报告要求都给出，不挑好看的那个** |
| **Y/Z 路径未做** | `pb_cheap` 的 maxDD −19.03pp 缺 §3.6.4 等暴露度对照，**未验证**（不是「不通过」） |
| **C 路径未做** | 历史 `confidence` 需逐日重跑 581 组锦标赛（≈8s/票/日），本轮不伪造分箱；需前向台账 |
| **腾讯限流** | 本轮第 47 只后整域失败，冷却与分批缓解但仍需换源；未来扩池应默认带 baostock 备胎 |
| **`001280` 被剔除** | 仅 228 根日线（新上市），不足 300 根预热；已在 `summary.json` 的 `stocks_skipped` 里记录 |
