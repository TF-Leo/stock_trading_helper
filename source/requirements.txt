# 依赖清单
#
# ── Python 版本 ────────────────────────────────────────────────────────────
# 支持 **Python 3.11+**（pandas 3.x / akshare 1.18 的最低要求就是 3.11）。
#
# ✅ 真机跑通（装依赖 + 全套测试 + CLI）：
#      Python 3.11.9  / numpy 2.2.6 / pandas 3.0.1 / akshare 1.18.29
#      Python 3.12.10 / numpy 2.2.6 / pandas 3.0.1 / akshare 1.18.29
#      Python 3.14.7  / numpy 2.3.5 / pandas 3.0.1 / akshare 1.18.29   ← marker 分支生效
# ⚠️ 3.13：本仓库验证机无法安装该解释器，只做了依赖解析验证，未运行。
#    若在 3.13 上出问题，请把 pytest 与 CLI 的原始报错反馈。
#
# 版本差异只来自 numpy 的 wheel 覆盖范围，与本项目代码无关：
#   pandas 3.0.x 的元数据是条件依赖
#       numpy>=1.26.0 ; python_version <  "3.14"
#       numpy>=2.3.3 ; python_version >= "3.14"
#   而 numpy 2.2.x 没有 cp314 wheel，故对 numpy 按 Python 版本分档。
#
# 注意：>=3.14 分支是**区间**（>=2.3.3,<3），解析器会取当时最新版，
# 实测出现过 2.3.5 与 2.5.4 两种结果 —— 都有 cp314 wheel、都能过全部门禁，
# 因此**不要求不同机器版本号相同**。要复现具体一位请显式 pip install numpy==2.3.5。

# 数据拉取
akshare==1.18.29
requests==2.32.5

# 数值计算
numpy==2.2.6; python_version < "3.14"
numpy>=2.3.3,<3; python_version >= "3.14"
pandas==3.0.1

# 测试
pytest==8.3.5
