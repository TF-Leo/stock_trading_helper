# 版本差异只来自 numpy 的 wheel 覆盖范围，与本项目代码无关：
#   pandas 3.0.x 的元数据是条件依赖
#       numpy>=1.26.0 ; python_version <  "3.14"
#       numpy>=2.3.3 ; python_version >= "3.14"
#   而 numpy 2.2.x 没有 cp314 wheel，故下方对 numpy 用 environment marker 分档：
#   < 3.14 锁定实测版本，>= 3.14 自动取满足 pandas 要求的新版。
#
# ── 实测状态（别把"能解析"当成"已验证"）─────────────────────────────────
#   ✅ 已在真机跑通全部测试与 CLI 的版本：

#        `pytest tests/ -q` → 47 passed（**冷克隆、无缓存同样 47 passed**）
#        `pwsh -File tools/check_gates.ps1 -Full` → PASS 35 / 退出码 0
#   ⚠️ 3.13 / 3.14：仅做了**依赖解析**验证（uv pip compile 通过），
#        未做运行验证（验证机无法安装这两个解释器）。
#        若你在 3.13/3.14 上跑出问题，请把 `pytest` 与
#        `python cli.py 600519 --json --fast` 的原始报错反馈——那是真 bug，不是环境问题。
